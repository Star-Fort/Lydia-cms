### Lydia CMS 🚀

[Читать на русском языке 🇷🇺](./README_RU.md) 

**Lydia CMS** (**C**ontent **M**anagement **S**ystem) is a simple, lightweight modular platform to build websites and web apps. Development of this platform started in **June 2022**. Instead of big and heavy code, you get a flexible core and "lego-brick" modules that you can easily turn on and off. 

### 🌟 Key Features:

* **🧱 Modular Design:** Use only the components and features that your project needs right now.
* **💾 HTML & SQL Support:** The system can work with simple static files (HTML) and dynamic databases (SQL).
* **🌐 Universal Platform:** Scales easily from a simple blog or personal website to complex real-time systems.
* **💬 Communication Tools:** Quick integration for online chats, VoIP phone calls, and live streaming modules.
